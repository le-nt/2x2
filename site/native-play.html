Windows launcher required. If your browser asks to open an external application, choose the 2x2 Launcher you installed. If it isn't installed, follow the setup instructions below. The browser can request a launch but cannot verify that Windows opened the client.

Install / configure the launcher

Download the 2x2 Native Launcher package, extract it, run install_windows.py on your own Windows PC, then use its settings window to select your installed Kanvas-compatible client executable.

2x2 currently supplies the selected map to the native launcher. Native client-specific command lines and multiplayer connectivity must be configured and tested with the client you use.
