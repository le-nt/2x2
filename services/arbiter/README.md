# The Moonic Game Arbiter
![Rust](https://img.shields.io/badge/rust-%23000000.svg?style=for-the-badge&logo=rust&logoColor=white)\
Creates & manages gameserver/render workers with RCCService and SOAP 🧼

## Prerequisites
[//]: # (warn about compilation from windows to linux, saying you need WSL)
- [Rust](https://www.rust-lang.org/tools/install) (rustc 1.70.0+)
- Cargo (included with Rust)
- Target `x86_64-unknown-linux-gnu` installed`

## Building
> [!CAUTION]
> Make sure to add the correct target before compiling

Do `cargo linux` and it should work 🥹
